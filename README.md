# Algorithms and Data Structures

C# implementations of fundamental algorithms and data structures, developed for the Algorithms and Data Structures course at Óbuda University. The repository includes weekly exercises, lab assignments, exam preparation solutions, and NUnit tests.

## Topics

- **Data structures:** Array-based and linked lists, stacks, queues, binary search trees, sets, hash tables, heaps, and priority queues.
- **Optimization:** Brute-force search, dynamic programming, backtracking, and branch and bound, including solutions to the knapsack problem.
- **Graphs:** Weighted and unweighted graph representations and traversal algorithms.
- **Programming paradigms:** Imperative, object-oriented, and functional programming concepts.

## Technologies

C# · .NET 8 · NUnit
